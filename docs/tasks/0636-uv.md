# 0636: Dense UV redraw and packing

- **Status:** in review
- **Authorization:** Pass 37 owner assignment, round 654 on published d7503d4e.
- **Requirements:** R-04, Q-06
- **Decisions:** ADR 0056, 0134
- **Implementation:** project implementer, independent test engineer and reviewer
- **PR:** Hub owns integration and publication

## Goal
Recheck the original Windows UV Reset capture and improve mixed/stretch redraw and packing where measured results and exact output support retention.

## Scope
Use the original 6,144-quad 1600×900 click fixture and published Windows binaries. Profile mixed winding, selection/seam and stretch redraw and rotated and axis-aligned pack. Bound scratch disk and reuse existing release objects.

## Likely files
Implementer owns src/editor/uv_editor.cpp and src/scene/uv.cpp. Tester owns independent scratch checks; coordinate additions to tests before editing. Lead owns this spec, docs/perf/0636-uv.md, changelog.d/654-uv.md and Hub receipt.

## Acceptance criteria
1. Bind installed and comparison Windows captures to executable hashes, verify actual Reset dispatch, pane output or bounded timeout.
2. Compare baseline and candidate in both run orders. Preserve exact pane pixels and pack coordinates, masked faces, chart quality and deterministic ordering. Report mixed, stretch, ordinary and small controls separately.
3. Keep only measurable improvements without a material regression; document rejected trials and limitations. Supply reproducible workloads and durable source-bound measurements.
4. Independently test and review the final source and documentation. Return a local commit without remote publication.

## Tests and checks to run
Use scratch projects, existing banks, machine build locks and Hub timed/functional queues. Verify selected editor/UV tests and the fragment. Route combined verification to Hub.

## Risks and edge cases
Different face order and style, per-pixel alpha rounding, seams, mask exclusion, degenerate/tied packing boxes, noisy timing, disk limits.

## Documentation to update
Round 654 fragment and UV performance report.

## Outcome
The installed Windows Reset workflow passed its original 60-second deadline. Both measured changes were retained after exact-output checks and reversed-order benchmarks. The [performance report](../perf/0636-uv.md) records the separate editor and packing results, including cases below the gain thresholds.
