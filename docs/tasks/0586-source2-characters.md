- **Status:** independently approved and verified in the joined Windows and Linux Workshop suites. [Cross-title results](0588-workshop-verification.md).

## Goal and ownership
Read compiled model, mesh, skeleton, material and texture resources for both target titles through the shared content resolver.

Owned paths or surfaces: src/scene/source2_model*, source2_resource* and source2_material*, dedicated resource/model tests. Coordinate registration and shared interface changes through the mounting round.

## Acceptance and verification
For each title separately verify bind pose, a weighted joint, a cutout material and detached-source reopen. Report unsupported resource versions. Derive independent tests from these criteria. Use scratch projects, run the Windows and Linux suites and relevant import/editor stress checks, and record exact commands and results. Cite repository revisions, primary format references and fixture provenance for consequential claims.

## Documentation
Own `changelog.d/604-source2-characters.md`. Include verified outcomes and applicable shared-document sections under ADR 0123. Supply user-facing changes to the Learn lesson and guide owners. Mark this spec done with test, review and PR evidence at closeout.

## Humanoid acceptance
For both Half-Life: Alyx and Counter-Strike 2, import a humanoid with its real bone naming conventions and check the bind pose and manual posing. Exercise the editor's automatic IK on both arms and legs and verify weighted vertex deformation, undo and preservation of the pose on save and reopen. On a fresh unskinned copy of each imported humanoid, place the humanoid markers, generate a rig and check bilateral arm and leg deformation. Preserve props and nonhumanoids without automatic humanoid changes. Record each fixture's provenance and distinguish generated format coverage from verified title assets.

## Material acceptance
Verify character and prop face-to-material slots, editable native materials, UV alignment, base colour, cutout and each supported texture channel. Resolve dependencies through mounted content and identify missing paths or unsupported formats. Check that the project owns the texture files. The independent joined workflow removes both mounts and temporary import cache before a cold reopen, compares the resulting render, and verifies that explicit reimport preserves user material edits.

## Format references and fixtures

- Resource directory offsets, KV3 lanes, and compressed texture layout were checked against [ValveResourceFormat resource format](https://github.com/ValveResourceFormat/ValveResourceFormat/blob/8d9f7d9da62a1a0189c6d00050e9653c762656de/docs/guides/read-resource.md), [binary KV3 reader](https://github.com/ValveResourceFormat/ValveResourceFormat/blob/8d9f7d9da62a1a0189c6d00050e9653c762656de/ValveResourceFormat/Resource/ResourceTypes/BinaryKV3.cs), [VBIB reader](https://github.com/ValveResourceFormat/ValveResourceFormat/blob/8d9f7d9da62a1a0189c6d00050e9653c762656de/ValveResourceFormat/Resource/Blocks/VBIB.cs) and [VTEX reader](https://github.com/ValveResourceFormat/ValveResourceFormat/blob/8d9f7d9da62a1a0189c6d00050e9653c762656de/ValveResourceFormat/Resource/ResourceTypes/Texture.cs).
- Skeleton joints, mesh draw calls, scale and texture slots were cross-checked against [SourceIO's VMDL importer](https://github.com/REDxEYE/SourceIO/blob/a50cea6ecf3e1837df89049f20f99741fbccf6fe/blender_bindings/source2/vmdl_loader.py), [unit conversions](https://github.com/REDxEYE/SourceIO/blob/a50cea6ecf3e1837df89049f20f99741fbccf6fe/library/utils/math_utilities.py) and [CS2 shader importer](https://github.com/REDxEYE/SourceIO/blob/a50cea6ecf3e1837df89049f20f99741fbccf6fe/blender_bindings/material_loader/shaders/source2_shaders/csgo_complex.py). The BC7 decoder follows [Khronos ARB_texture_compression_bptc](https://registry.khronos.org/OpenGL/extensions/ARB/ARB_texture_compression_bptc.txt), including the prescribed modes, partitions and anchors.
- `tests/test_source2_model.cpp` generates small original binary resource containers with v1 raw and v5 LZ4 KV3, VBIB/MBUF, a two-joint model, a static prop, cutout materials and VTEX images. Real resources are kept in scratch only. The Counter-Strike 2 sample is `agents/models/ctm_sas/ctm_sas.vmdl_c` from Steam game 730 build 26445667. The Alyx samples are [`models/alyxmp/avatar.vmdl_c`](https://github.com/Requiem-Software/AlyxMP/tree/84685425f2c1771995c7f269fe1e1c0852a72d5f) and [`models/biped_standard/player_body_biped.vmdl_c`](https://github.com/mrwoods74821/hlvr-coop/tree/7d588675be8600f92148d47f48d188249b346dd1/WorkshopAddonCompatibilityPlugin/sources/Player-Body). Both depend on Alyx base-game materials beyond the files supplied by those add-ons.
- The reader reports unsupported resource headers, NTRO or legacy VKV3 data, unknown codecs and unimplemented shader operations. Meshoptimizer and Zstandard streams require builds with Blender's libraries. Texture arrays, volumes, cubemaps and draw primitives other than triangles are outside the character material reader's supported subset.

## Reimport identity

Include the conversion or authored material variant where outputs differ. Identity must survive changes to bytes, draw order, source location, cache location and process. Joined verification imports equal basenames from different folders, edits a native material, reorders the sources and changes texture content, moves the cache, then reimports twice. Verify per-face assignments, updated pixels, retained edits and stable project artifact counts on Windows and Linux before publication.

The material reader records the compiled virtual VMAT path, including for an unresolved VMAT. It records the compiled VTEX path with a conversion role for base color, linear data, each normal convention, packed roughness and metalness extracted from alpha. The pointer and decoded file path serve only as lookup keys for this import. Maps supply IDs for their own per-placement variants.

The focused Windows regression mounts the first and second versions from different directories, changes the cache directory, reverses material slots with equal basenames, and replaces the bytes of one base texture. Both imports use the same virtual IDs, the updated pixels appear in the second import, and the native slots still distinguish the materials. The test also checks both normal conversions, shared packed roughness and the ID for a missing material.

## Review corrections

- SAS lenses now uses the authored green channel of `g_tMetalness`. The native scalar map has 256 of 256 texels equal to `1.0`, with the stable role `metalness-green`. The multi-slot regression now asserts the authored green value in every RGB channel of the converted scalar PNG. R8 UNORM keeps red only. SAS and SWAT materials that request anisotropic gloss report the unsupported feature and name the compiled `g_tAnisoGloss` path. [CS2 character shader](https://github.com/ValveResourceFormat/ValveResourceFormat/blob/8d9f7d9da62a1a0189c6d00050e9653c762656de/Renderer/Shaders/csgo/csgo_character.frag.slang), [R8 decoder](https://github.com/ValveResourceFormat/ValveResourceFormat/blob/8d9f7d9da62a1a0189c6d00050e9653c762656de/ValveResourceFormat/TextureDecoders/DecodeR8.cs).
- KV3 now charges copied keys, strings and blobs against one expansion budget before copying. Its text/blob ceiling is 128 MiB, with a lower cap for small wire payloads. Each renderable import budgets decoded mesh buffers and temporary decoded streams together at 256 MiB, and limits the aggregate draw vertex ranges, corners and dense weights to 2 million, 6 million and 16 million respectively. Small generated resources exercise rejection of repeated keys and values, multiple compressed streams, and repeated draws before staging their output.
- Embedded PNG and JPEG dimensions are checked against VTEX before calling the existing image codecs. PNG checksums, framing and bounded scanline expansion are validated. The regression passes valid PNG and JPEG and refuses empty images, CRC corruption, oversized or mismatched dimensions and a truncated JPEG. Pinned ValveResourceFormat fixtures `PNG_DXT5_gray_button_on_png.vtex_c` and `JPEG_DXT5_halloween_jpg.vtex_c` also imported into two independent slots.
- The locked Windows scratch build `C:\blab\build-low.bat C:\blwt604\build\source2-identity release tests source2-604-review-final` rebuilt the three reader units and the focused tests with the same ABI and flags. The `verify.ps1` invocation above passed **352 checks** and all six actual title fixture imports. The additional encoded VTEX test log is under `C:/blwt604/build/source2-identity/run/actual-embedded/results.log`. No Linux retry was scheduled for this correction.
- The partial-import correction limits base-alpha extraction to materials that use alpha-packed metalness. An opaque retro-reflective `vr_complex` material with a missing green-channel map retains its authored scalar even when its base texture has opaque texels. The fixture also verifies that the missing VTEX path remains in the notes. The locked MSVC rebuild with owner `source2-604-retro-metalness` passed **362 focused checks**. [Alyx complex shader](https://github.com/ValveResourceFormat/ValveResourceFormat/blob/8d9f7d9da62a1a0189c6d00050e9653c762656de/Renderer/Shaders/hlvr/vr_complex.slang).
- The follow-up restores alpha-packed metalness for `vr_simple`, `vr_xen_foliage` and `csgo_simple`, and restores the implicit opaque fallback when an unrecognized shader declares the feature without a separate map. Xen foliage can use the same alpha for both opacity and metalness. Known green-channel shaders and the scalar mode keep their own inputs. The same new fixture registered 21 failures in 84 checks against the previous reader, then the locked `source2-604-alpha-restored` rebuild passed all **436 focused checks**, including missing and absent retro-reflective inputs. [Alyx simple shader](https://github.com/ValveResourceFormat/ValveResourceFormat/blob/8d9f7d9da62a1a0189c6d00050e9653c762656de/Renderer/Shaders/hlvr/vr_simple.slang), [Alyx Xen foliage shader](https://github.com/ValveResourceFormat/ValveResourceFormat/blob/8d9f7d9da62a1a0189c6d00050e9653c762656de/Renderer/Shaders/hlvr/vr_xen_foliage.frag.slang), [CS2 simple shader](https://github.com/ValveResourceFormat/ValveResourceFormat/blob/8d9f7d9da62a1a0189c6d00050e9653c762656de/Renderer/Shaders/csgo/csgo_simple.frag.slang).
