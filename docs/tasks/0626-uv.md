## Goal
Measure complete UV editing and mapping actions on complex meshes and retain optimizations that preserve their results.

## Scope
Inventory UV commands, editor gestures, seams, islands, projection, unwrap, pack, density, stretch and available relax or pin behavior. Use existing implementations and explicit coverage gaps. Shared build infrastructure belongs to the Hub.

## Likely files
The implementer owns a standalone benchmark in tools/bench/ and evidence-backed changes in src/scene/uv.cpp. The tester owns UV-specific checks in tests/test_modeling.cpp if required. The lead owns this spec, docs/perf/0626-uv.md, changelog.d/644-uv.md and Hub scratch. Coordinate file additions or overlaps before editing.

## Acceptance criteria
1. Map each action to source and a real workload or a stated gap. Exercise production actions with valid selections and verify their effects.
2. Include ordinary and constrained CPU evidence where relevant, large connected and fragmented fixtures, traversal and allocation costs, plus a baseline control. Claim gains only with repeated paired timings under a Hub window and matching outputs.
3. Preserve seams, masked coordinates, supported pins, island membership and deterministic valid packing. Document unsupported actions precisely.
4. Give the inventory to 0630 and return independently tested and reviewed evidence.

## Tests and checks to run
Run focused production-action checks and relevant existing UV tests and stress using isolated project/trash. Verify package identity before reuse. Route affected Windows and Linux groups plus editor to the Hub for joined verification if a new build is required.

## Risks and edge cases
Many tiny islands, one large chart, ambiguous seams, non-manifold edges, partially selected meshes, degenerate faces, ties in pack order, unsupported editor operations and solver differences across builds.

## Documentation to update
Record per-tool evidence and limitations in docs/perf/0626-uv.md and the round fragment.

## Outcome
The retained projection change eliminated one temporary allocation per selected face. See [the benchmark and coverage report](../perf/0626-uv.md) and Pass 36 Hub receipt 0626. The separate packing trial showed mixed default-mode timings. The separate code reviewer approved the projection-only change. Windows lite and Linux production UV/seams/F9 each passed 110 assertions; the Linux oracle matched 144 cases byte for byte. Hub owns joined verification and publication.
