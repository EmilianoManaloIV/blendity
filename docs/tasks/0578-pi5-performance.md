## Verification and limits

- Local Ubuntu WSL reports x86_64, GCC targets x86_64-linux-gnu, and the native X11 headers are present. There is no AArch64 C++ compiler, target libc/X11 development sysroot or QEMU user executable in the inspected toolchains. The installed Visual Studio tools target Windows x86/x64. A Linux ARM64 application build was unavailable locally. The configured CI jobs use regular Ubuntu runners and a separate Apple ARM build.
- In WSL, the mock-compiler link-argument regression failed against the original script (ARM64 enabled x64 TBB) and passed against the candidate. It exercises native x64 discovery, forced dependency-free x64, default ARM64 alongside x64 libraries, and explicit ARM64 libraries without SSE switches. This verifies selection without compiling ARM instructions. Compiler wrappers remain supported. This work covers native Linux and Linux cross compilers targeting a different CPU. Cross-OS toolchains and GCC multilib switches need separate treatment.
- [Ranked evidence and allocation estimates](../perf/0578-pi5-baseline.md) and [Pi acceptance protocol](../perf/0578-pi5-acceptance.md). Linux dependency-free builds include the X11 platform, scalar CPU rasterizer and built-in codecs. Vulkan requires an explicitly provisioned native optional bundle with Vulkan headers, shaderc and the build's TBB marker. Raspberry Pi driver limits and the physical board's latency and memory headroom remain unmeasured.
- The original CMake failed the ARM64 case by enabling x64 TBB. All five candidate CMake configurations passed in WSL with simulated 64-bit target metadata, a dummy compiler, and stub Threads/X11 discovery. Generated build files verified native x64, default ARM64, explicit ARM64 bundle, a legacy cached x64 path on ARM64 and forced dependency-free x64. Neither these configurations nor the shell fixtures exercise an ARM64 binary. The physical protocol assertions passed a positive fixture and rejected five distinct incorrect edit/reopen traces. Independent review approved the revised implementation and verification protocol.
