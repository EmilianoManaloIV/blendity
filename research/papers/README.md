# Drop your papers here

Put research papers in this folder (PDF, TXT, MD, TeX, BibTeX, DOCX, HTML, EPUB). You can:

- copy them into this folder in Explorer, Finder or a file manager, **or**
- drag them onto the running Blendity window. The editor copies them here and opens the **Research** tab.

Then ask Claude Code to implement something from a paper, for example:

> Read `research/papers/taubin95.pdf` and implement λ|μ smoothing as a Blendity research feature.

> Implement the "As-Rigid-As-Possible" deformation from `research/papers/arap.pdf` as an Edit Mode operator.

See `../README.md` for the workflow and `../FEATURES.md` for which paper produced which feature.
